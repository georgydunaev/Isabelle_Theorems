# Isabelle_Theorems

This repository contains formalizations of mathematical theorems in the Isabelle proof assistant. The main file, Jech.thy, is a formalization of set theory and includes a lemma stating that the power set of S is not a subset of S.

## Contents

- **Jech.thy**: A formalization of set theory in the Isabelle proof assistant. This file defines a set W and includes a lemma ex_1_2' which states that the power set of S is not a subset of S.

## Usage

To use the contents of this repository, you will need to have Isabelle installed on your system. You can then import the Jech.thy file into your own Isabelle theories to use the definitions and lemmas provided.
